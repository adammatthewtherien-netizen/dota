# TI 2026 Spoiler-Free VODs — Group Stage Test

This build contains the completed Aug. 13–16 Swiss Group Stage plus Elimination Round series.

## Important
The site does NOT render scores or winners. The completed scorelines were used only to encode how many games exist in each series.

Later games are hidden until the previous game is marked finished:
- Game 2 is hidden before Game 1 is finished.
- Game 3 is hidden before Game 2 is finished.
- If a series ended in two games, you only discover that after finishing Game 2.

A handful of official English individual-game YouTube IDs are already connected. Remaining slots use `player.html` as a spoiler-safe placeholder for testing.
